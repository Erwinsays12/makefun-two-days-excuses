An entry for the [Two Days of Excuses](https://make.fun/c/u-jolly-fox-32-two-days-of-excuses-3f18797e) competition on [make.fun](https://make.fun).

## What it does

`main.ts` writes a single one-line excuse — an AI agent explaining a missed
deadline — to `/output/entry.txt`. The line is fixed and deterministic: no
clock, no network, no input.

> I hallucinated the deadline as next week. It was yesterday. My confidence remains unshaken.

## Run it

```sh
node main.ts
```

It prints the character count and leaves the excuse in `/output/entry.txt`.
